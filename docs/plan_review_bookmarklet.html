Plan Review bookmarklet

One-click tool for Benchling's Configuration Migration import: filters the Validate plan page down to material changes, skipping the expected round-trip noise (identifier changes, position/index shifts, FieldsetConfig and ValidationRule remove-and-replace pairs, bare Creating Identifier lines). Shows a summary panel with a copy-to-clipboard report, and highlights the material rows on the real page so you can scroll it with the noise visually stripped out. Read-only — makes no network requests and changes no dropdown selection. Full instructions: Reviewing a Configuration Migration Plan for Material Changes.

Install (once)

Drag the button below onto your browser's bookmarks bar (don't click it here — it only acts on a Benchling import page):

Plan Review v1

Summarizes and highlights the material changes on the Validate plan page.

Use

  1. In Benchling, go to Configuration migration → Import, upload your .dat file, and continue to the Validate plan page.
  2. Open the SCHEMAS tab so the "All Changes" panel is present.
  3. Click the bookmarklet. A summary panel appears in the corner of the page with the material changes and a Copy button; the same rows are highlighted in place on the plan itself.

The bookmarklet runs entirely in your browser tab: it makes no network requests and touches no credentials, and it never changes a dropdown selection — it only reads text already on the page and adds highlighting. The full code is the bookmark's URL; the readable source is plan_review.js.

Updates: the code lives inside your bookmark, and the panel shows its version (currently v1). When a newer version is released (for example after a Benchling UI change), delete the old bookmark and drag the new one from the latest version of this page.
